# 2. Регламент управляющих

Управляющие: **Паша П.**, **Паша Е.**, **Даня**.

Управляющий — это уровень «работать НАД складом, а не НА складе». Его продукт — работающая система: правильные люди на местах, понятные процессы, выполненные планы и прибыль. Ежедневную операционку ведут главные по зонам.

## 2.1. Распределение направлений

| Управляющий | Направление | Главные по зонам в подчинении |
|---|---|---|
| Паша П. | Складская зона (хранение) + зона возвратов | Никита, Денис |
| Паша Е. | Зона сборки и отправки (совместно с Даней) | Степан |
| Даня | Зона сборки и отправки (совместно с Пашей Е.) | Степан |

Общие для всех троих вопросы (деньги, крупные закупки, найм/увольнение, изменение регламента, премии) решаются коллегиально. Правило принятия решений: `[заполнить: единогласно / большинством 2 из 3 / решает ответственный за направление]` — **рекомендуется «большинством 2 из 3»**, чтобы ни один вопрос не зависал.

## 2.2. Обязанности управляющего

**Люди:**
- Финальное решение о найме и увольнении (по представлению главных по зонам).
- Утверждение графиков, отпусков, премий и депремирований.
- Развитие главных по зонам: еженедельная обратная связь, помощь в сложных ситуациях, обучение управлению.
- Кадровый резерв: у каждой ключевой роли должен быть готовящийся заместитель.

**Процессы и качество:**
- Утверждение и изменение регламента и СОПов (см. порядок в README).
- Контроль KPI направлений по еженедельным отчётам, разбор отклонений.
- Решения по системным проблемам (повторяющаяся ошибка — это проблема процесса, а не сотрудника).

**Внешний контур:**
- Маркетплейсы / клиенты: кабинеты, споры, штрафы, требования к отгрузкам — `[закрепить за конкретным управляющим]`.
- Перевозчики и поставщики: договоры, графики забора, претензии.
- Аренда, оборудование, расходники, инфраструктура склада.

**Деньги:**
- Бюджет склада, фонд оплаты труда, премиальный фонд.
- Утверждение закупок сверх лимита главного по зоне (лимит — п. 3.4).

## 2.3. Чего управляющий НЕ делает

- Не ставит задачи линейным сотрудникам через голову главного по зоне (кроме ЧП). Увидел проблему — сказал главному зоны, спросил с главного.
- Не отменяет распоряжения главного по зоне при его подчинённых. Не согласен — разбор один на один, решение объявляет сам главный.
- Не принимает «жалобы через голову» как решения: выслушал сотрудника — вернул вопрос главному зоны (кроме жалоб на самого главного — их управляющий разбирает лично, см. п. 8.7).
- Не держит договорённости в устной форме: всё, что меняет правила работы, — фиксируется письменно.

## 2.4. Регулярный ритм управляющего

| Ритм | Что делает |
|---|---|
| Ежедневно | Читает вечерние отчёты зон (п. 9.4). Реагирует на красные флаги: срыв отгрузки, крупная недостача, конфликт, невыход людей |
| Еженедельно | Планёрка с главными по зонам (п. 9.5): метрики, проблемы, решения. Один обход склада «глазами клиента» |
| Ежемесячно | Итоги месяца: KPI, премии, инвентаризация, план на месяц. Встреча 1-на-1 с каждым своим главным по зоне (30 мин: что получается, что мешает, что нужно) |
| Ежеквартально | Полная инвентаризация. Пересмотр норм и KPI. Ревизия регламента (что устарело) |

## 2.5. Полномочия и ответственность

Управляющий отвечает перед партнёрами за результат своего направления:

| Направление | Ключевые показатели ответственности |
|---|---|
| Сборка и отправка (Паша Е., Даня) | Отгрузка в срок (SLA), % ошибок сборки, штрафы маркетплейсов по вине сборки |
| Склад (Паша П.) | Точность остатков, скорость приёмки, отсутствие потерь, «не найдено» при сборке |
| Возвраты (Паша П.) | Скорость разбора возвратов, корректность оценки, возврат ликвидного товара в продажу |
