# 9. KPI, отчётность и мотивация

## 9.1. Принципы

1. **Меряем мало, но главное.** У каждой роли 3–5 показателей, не больше.
2. **Сначала замер, потом норма.** Первые 2–4 недели нормы не караются — идёт замер фактической производительности. Затем управляющие утверждают нормы приказом, и они появляются в квадратных скобках этого раздела.
3. **Показатели видимы.** Каждый сотрудник знает свои цифры за вчера/неделю/месяц (доска зоны или чат). KPI не должны быть сюрпризом в день премии.
4. **Премия — по правилам, а не по настроению.** Формула известна заранее; решение по премиям — управляющие по представлению главных.

## 9.2. KPI по ролям (сводная таблица)

| Роль | Показатели | Стартовая норма |
|---|---|---|
| Сборщик | Скорость сборки; % ошибок; готовность к cut-off; дисциплина | `[X]` заказов/час; ошибок ≤ `[0,5 %]`; 100 % к cut-off |
| Разборщик возвратов | Скорость разбора; срок ≤ 48 ч; корректность категорий; фото спорных | `[X]` ед./час; 100 % в срок; ≥ `[97 %]` корректность |
| Кладовщик | Приёмка/размещение в день поступления; точность остатков; «не найдено»; скорость пополнения | 100 % в день; расхождения ≤ `[1 %]`; «не найдено» ≤ `[0,2 %]`; ≤ `[30 мин]` |
| Главный по зоне | KPI зоны (агрегированные показатели его людей); отчёт ежедневно вовремя; укомплектованность и обученность; порядок в зоне | 100 % отчётов; KPI зоны в норме |
| Управляющий | SLA отгрузок; штрафы МП по вине склада; точность остатков; себестоимость обработки заказа; текучесть | по бизнес-плану |

## 9.3. SLA стыков между зонами

Эти нормативы — общие обязательства зон друг перед другом; их срыв разбирается на еженедельной планёрке:

| Стык | Норматив |
|---|---|
| Склад → Сборка: пополнение по запросу | ≤ `[30 минут]` |
| Склад → Сборка: реакция на «не найдено» | ≤ `[15 минут]` |
| Возвраты → Склад: передача категории А | ежедневно, ≤ `[24 ч]` после разбора |
| Возвраты: разбор возврата с момента поступления | ≤ `[48 часов]` |
| Склад: приёмка поставки | в день поступления |
| Сборка: готовность партии к cut-off | 100 % за `[30 минут]` до забора |

## 9.4. Ежедневная отчётность

Главный каждой зоны — до `[20:00]` в общий чат по шаблону (приложение 12.5):

- Факт дня в цифрах (собрано/разобрано/принято/размещено).
- Ошибки и инциденты + что сделано.
- Проблемы, которые нужно решить не на уровне зоны (запрос управляющим).
- Люди: кто был, кто завтра, есть ли дыры.

**Правило красного флага:** срыв отгрузки, крупная недостача, травма, конфликт — сообщается немедленно лично курирующему управляющему, а не вечером в отчёте.

## 9.5. Еженедельная планёрка (главные + управляющие)

- Когда: `[понедельник, 10:00]`, 30–60 минут. Ведёт: `[один из управляющих по очереди]`.
- Повестка (шаблон 12.10): цифры недели по зонам → срывы SLA стыков и их причины → решения прошлой недели: сделано/нет → проблемы и предложения → план недели.
- Все решения — письменно в протокол (чат/документ): формулировка, ответственный, срок. Без записи решения не существует.

## 9.6. Ежемесячно

- Итоги месяца по KPI — основа премий.
- Управляющие проводят 1-на-1 с каждым главным по зоне.
- Комиссия по браку (СОП-9), сверка итогов инвентаризаций.

## 9.7. Структура мотивации (рамка)

Конкретные суммы устанавливают управляющие; рамка такая:

| Часть | Кому | За что |
|---|---|---|
| Оклад/ставка | Все | Выход и выполнение обязанностей |
| Премия за результат (`[до 20–40 %]` дохода) | Линейные | Выполнение личных KPI: объём × качество. Ошибки и нарушения снижают премию по шкале п. 8.5 |
| Премия зоны | Главные по зонам | KPI зоны + отсутствие срывов SLA + управленческие задачи месяца |
| Разовые премии | Все | Сверхрезультат, предложение, давшее измеримый эффект, подхват чужой зоны в аврал |

Правила премий объявляются заранее и не меняются задним числом.
