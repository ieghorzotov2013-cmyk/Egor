# 12. Приложения: чек-листы и шаблоны

Чек-листы печатаются и висят в своих зонах. Отметки — ежедневно, лист подписывает главный зоны.

## 12.1. Чек-листы открытия смены (главный зоны)

**Общее для всех зон:**
- ⬜ Все сотрудники зоны на месте (невыходы → план Б, отметка в табеле)
- ⬜ Оборудование работает (сканеры заряжены, принтеры этикеток печатают, система доступна)
- ⬜ Проходы свободны, зона в порядке после вчера
- ⬜ Планёрка зоны проведена: план дня, распределение, приоритеты

**Сборка и отправка (Степан), дополнительно:**
- ⬜ Объём заказов на сегодня оценён, людей хватает (нет → запрос помощи ДО обеда)
- ⬜ Времена cut-off/заборов на сегодня известны команде
- ⬜ Расходники упаковки на день есть (пакеты, коробки, скотч, этикетки)
- ⬜ Вчерашние «хвосты» (несобранные/неотгруженные) взяты в работу первыми

**Склад (Никита), дополнительно:**
- ⬜ План поставок на сегодня известен, место приёмки готово
- ⬜ Очередь запросов на пополнение пуста или взята в работу
- ⬜ Вчерашние «не найдено» разобраны (причины найдены)
- ⬜ Сегмент циклической инвентаризации на сегодня назначен

**Возвраты (Денис), дополнительно:**
- ⬜ Ожидаемые возвратные партии на сегодня известны
- ⬜ Очередь разбора в сроке (нет возвратов старше 48 ч; есть → в приоритет)
- ⬜ Накопитель категории А передан на склад (вчерашний)

## 12.2. Чек-лист закрытия смены (главный зоны)

- ⬜ План дня выполнен / невыполненное зафиксировано с причиной и перенесено
- ⬜ Все передачи между зонами закрыты листами передачи
- ⬜ Зона убрана: товар в ячейках/накопителях, мусор вынесен, проходы свободны
- ⬜ Оборудование на зарядке/на месте, помещения закрыты
- ⬜ Вечерний отчёт отправлен (шаблон 12.5)
- ⬜ План и расстановка на завтра понятны

## 12.3. Чек-лист разбора возврата (разборщик)

1. ⬜ Сверил номер отправления с реестром, статус «в разборе»
2. ⬜ Спорный/дорогой товар — фото ДО вскрытия
3. ⬜ Тот ли товар внутри (артикул, размер, цвет — ловим подмену)
4. ⬜ Комплектность (все части, бирки, ярлыки, упаковка производителя)
5. ⬜ Следы носки/использования, запахи, повреждения
6. ⬜ Работоспособность `[для техники]`
7. ⬜ Категория: **А** (в сток) / **Б** (подготовка/уценка) / **В** (брак) — сомнение = вопрос Денису
8. ⬜ Категория и причина возврата внесены в систему, спорные — с фото
9. ⬜ Товар физически в свой накопитель (А/Б/В)

## 12.4. Чек-лист первого дня новичка (главный зоны)

- ⬜ Документы оформлены, инструктаж по ТБ пройден под подпись
- ⬜ Экскурсия по складу, шкафчик выдан
- ⬜ Наставник назначен и предупреждён
- ⬜ Выданы регламенты: разделы 1, 8 + регламент его роли; подписан лист ознакомления
- ⬜ Доступ/логин в систему учёта создан
- ⬜ Первая задача выполнена в паре с наставником
- ⬜ В конце дня: короткая обратная связь, вопросы новичка разобраны

## 12.5. Шаблон вечернего отчёта зоны (в общий чат, до 20:00)

```
📦 [Зона] — отчёт за [дата]
Люди: [вышло X из Y; завтра выходят: …]
Сделано: [собрано/отгружено N; принято/размещено N; разобрано возвратов N (А/Б/В: …)]
Ошибки и инциденты: [что случилось → что сделали → что изменим]
Срывы SLA: [нет / какие и почему]
Нужно от управляющих: [решения, закупки, люди — или «ничего»]
Завтра главное: [1–3 приоритета]
```

## 12.6. Лист передачи между зонами

| Поле | Значение |
|---|---|
| Дата, время | |
| Откуда → куда | напр. Возвраты → Склад |
| Что и сколько | список позиций / итог мест |
| Передал (подпись) | |
| Принял после пересчёта (подпись) | |
| Расхождения | нет / акт №___ |

## 12.7. Акт расхождения (приёмка/отгрузка/передача)

Дата; процесс (приёмка поставки / возвраты / отгрузка / передача между зонами); документ-основание (накладная/реестр №); что заявлено; что по факту; разница; фото (да/нет); кто обнаружил; подписи двух сторон; решение (заполняет управляющий).

## 12.8. Журнал нарушений зоны (ведёт главный)

| Дата | Сотрудник | Нарушение | Ступень (1/2/3/4) | Мера | Подпись сотрудника |
|---|---|---|---|---|---|

Записи старше 6 месяцев в шкале не учитываются.

## 12.9. Лист ознакомления с регламентом

«С регламентом работы склада (разделы: ___) ознакомлен, обязуюсь выполнять».

| ФИО | Должность | Дата | Подпись |
|---|---|---|---|

## 12.10. Повестка еженедельной планёрки

1. Цифры недели по зонам (3 мин на зону: факт, ошибки, SLA)
2. Статус решений прошлой недели (сделано / нет — почему)
3. Срывы и проблемы недели → причины → решения
4. Предложения по улучшениям (от главных)
5. План следующей недели, пики, поставки, отгрузки
6. Протокол: решение — ответственный — срок

## 12.11. Матрица RACI по ключевым процессам

О — отвечает (делает и отвечает за результат), У — утверждает, К — консультируется, И — информируется.
