# 4. Регламент сборщика

**Зона:** сборка и отправка. **Непосредственный руководитель:** Степан (главный по зоне сборки и отправки).

Задача сборщика — собрать заказ **точно** (тот товар, тот размер/цвет, то количество), **аккуратно** (упаковка защищает товар) и **вовремя** (к отгрузке дня). Точность важнее скорости: одна ошибка сборки стоит дороже десяти минут — это возврат, штраф маркетплейса и злой клиент.

## 4.1. Обязанности

- Собирать заказы по заданиям, которые выдаёт главный по зоне или система, — в порядке приоритета, не выбирая «удобные».
- Работать со сканером/системой: каждая позиция подтверждается сканированием штрихкода ячейки и товара `[если сканеров нет — двойной визуальной сверкой артикула и размера]`.
- Проверять каждую позицию перед упаковкой: артикул, размер/цвет, количество, товарный вид (грязный/мятый/повреждённый товар в заказ не кладём — см. п. 4.3).
- Упаковывать по стандарту упаковки (СОП-4): правильный размер пакета/коробки, защита хрупкого, этикетка ровно, старые этикетки удалены.
- Ставить готовый заказ в зону готовых в отведённое место — не «где удобно».
- Поддерживать порядок на рабочем месте в течение смены и сдавать место чистым.
- Сообщать главному по зоне обо всех нестандартных ситуациях **сразу**, а не в конце смены.

## 4.2. Пошаговый порядок работы (краткая версия СОП-4)

1. Получи задание → возьми тару.
2. Иди по маршруту → в ячейке отсканируй ячейку и товар → сверь артикул, размер, количество.
3. Собрал всё → контрольная проверка состава заказа целиком.
4. Упакуй по стандарту → наклей этикетку → отсканируй как «собран».
5. Поставь в зону готовых заказов в свою секцию.
6. Возьми следующее задание.

## 4.3. Нестандартные ситуации — что делать

| Ситуация | Действие сборщика |
|---|---|
| Товара нет в ячейке / не хватает количества | Не бросай заказ и не бери «похожий»! Отметь «не найдено», сообщи главному по зоне — дальше по СОП-8 отрабатывает складская зона |
| Товар повреждён / грязный / без бирки | В заказ не класть. Отложи с пометкой, сообщи главному; товар уходит в брак/на проверку (СОП-9), тебе дают замену из ячейки |
| Штрихкод не сканируется / не совпадает с товаром | Стоп, зови главного. Самому «пробивать другой похожий» запрещено — так рождается пересорт |
| Сомневаешься в чём угодно | Спроси главного. Вопрос — это 30 секунд, ошибка — это возврат и штраф |

## 4.4. Запрещено

- Класть в заказ товар, не подтверждённый сканированием/сверкой («и так вижу, что тот»).
- Собирать несколько заказов в одну тару без разделителей.
- Оставлять незавершённый заказ без пометки и передачи главному.
- Самостоятельно менять товар на аналогичный.
- Выносить товар из зоны без задания.

## 4.5. KPI сборщика

| Показатель | Норма (стартовая, уточняется по замерам) |
|---|---|
| Скорость сборки | `[X заказов или строк/час]` — норма устанавливается после 2 недель замеров |
| Ошибки сборки (пересорт, недовложение, лишнее) | не более `[0,5 %]` заказов; цель — 0 |
| Заказы, собранные к cut-off | 100 % |
| Порядок на рабочем месте, дисциплина | без замечаний |

Учёт ошибок ведёт главный по зоне персонально по каждому сборщику. Премирование/депремирование — по разделу 9.
