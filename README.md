# Сайт Егора

Простой личный сайт, которым можно полностью управлять с телефона.

## Как устроен сайт

- **`index.html`** — сама страница сайта (дизайн). Её трогать не нужно.
- **`content.json`** — всё содержимое сайта: заголовок, текст «Обо мне», новости, контакты. Меняете этот файл — меняется сайт.

## Как управлять сайтом с телефона

### Способ 1: через Claude (проще всего)

Откройте Claude Code на телефоне (приложение Claude или claude.ai/code), выберите этот репозиторий и напишите обычным языком, что поменять. Например:

> «Добавь новость: сегодня я запустил свой проект»
>
> «Поменяй текст обо мне на …»
>
> «Добавь мой телеграм @egor»

Claude сам внесёт изменения и опубликует их.

### Способ 2: через приложение GitHub

1. Установите приложение **GitHub** из App Store / Google Play и войдите в свой аккаунт.
2. Откройте репозиторий → файл `content.json` → кнопка редактирования (карандаш).
3. Поменяйте текст и нажмите **Commit changes**.

## Как включить публикацию сайта (один раз, бесплатно)

Сайт публикуется через **GitHub Pages**:

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите Source: **Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через пару минут сайт будет доступен по адресу вида
   `https://ieghorzotov2013-cmyk.github.io/Egor/`

После этого любое изменение `content.json` автоматически обновляет сайт в течение 1–2 минут.

## Что можно менять в `content.json`

```json
{
  "заголовок": "Крупный заголовок наверху",
  "подзаголовок": "Строка под заголовком",
  "раздел_о_себе": "Название раздела (по умолчанию «Обо мне»)",
  "о_себе": "Текст в этом разделе",
  "новости": [
    { "дата": "5 августа 2026", "текст": "Текст новости" }
  ],
  "контакты": {
    "email": "ваша почта",
    "telegram": "@ваш_ник (можно оставить пустым)",
    "телефон": "+7 ... (можно оставить пустым)"
  },
  "подвал": "Строка внизу страницы (можно не указывать)"
}
```

Пустые поля (например, телефон) просто не показываются на сайте.
