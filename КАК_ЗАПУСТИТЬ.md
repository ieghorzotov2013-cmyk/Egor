# Проверка заказов в статусе «на разборе возвратов» (МойСклад)

Скрипт `check_returns_status.py` заходит в API МойСклад, находит заказы покупателя
со статусом «на разборе возвратов» и выводит их список, количество и сумму.

> Из окружения Claude Code запустить нельзя — там закрыт доступ в интернет к МойСклад.
> Поэтому запускаем на своём компьютере (Windows / Mac / Linux).

---

## Шаг 1. Скачать файлы

Скачайте на компьютер два файла из ветки:
- `check_returns_status.py`
- (этот файл с инструкцией)

## Шаг 2. Положить токен

Рядом со скриптом создайте текстовый файл с именем **`ms_token.txt`**
и впишите в него только токен (одной строкой), например:

```
788cadd3225e2fe58aff8fce7fe8a1cb197eef3e
```

Сохраните.

## Шаг 3. Запустить

### Windows
1. Установите Python с https://python.org (при установке отметьте «Add Python to PATH»).
2. Откройте папку со скриптом, в адресной строке проводника напишите `cmd` и нажмите Enter.
3. Введите:
   ```
   python check_returns_status.py
   ```

### Mac / Linux
В терминале перейдите в папку со скриптом и выполните:
```
python3 check_returns_status.py
```

---

## Что вы увидите

```
Статус: «на разборе возвратов»
Найдено заказов: 7
----------------------------------------------------------------------
00123          2026-06-20 14:30        12 500,00 ₽
...
----------------------------------------------------------------------
Итого по сумме: 84 300,00 ₽
```

Если название статуса в МойСклад чуть другое — скрипт напишет, какие статусы есть.
Тогда запустите с точным названием, например:
```
python check_returns_status.py "разбор возвратов"
```
